## 📖 Sobre o Projeto

O **CINE PRO TV 2026** é uma plataforma moderna e completa de entretenimento digital desenvolvida por **Jonas**, projetada para entregar a melhor experiência de streaming tanto na **Web (Nuvem 24h)** quanto em **Servidor Local Híbrido de Alta Performance (Windows/Linux/Android)**.

Conta com um catálogo de **mais de 780 canais estruturados e auditados**, separação inteligente por categorias, interface estilo cinema (*Glassmorphism Dark Pro*), suporte a controle remoto via celular por Wi-Fi, guia de programação ao vivo (EPG) e uma central completa de rádios brasileiras.

## ✨ Destaques Tecnológicos da Central

- 🚀 **Modo Híbrido Nuvem & Local:** Roda direto no navegador via HTTPS na nuvem pelo [Netlify](https://cineprotvv6-0628b4.netlify.app) e com aceleração máxima de proxy local em `localhost:8080`.
- 📱 **Controle Remoto Wi-Fi pelo Celular:** Aponte a câmera do seu smartphone para o QR Code na tela da TV ou PC e controle tudo (trocar de canal, volume, modo cinema) sem levantar do sofá!
- 🎛️ **Grade Flex-Wrap & Busca em Tempo Real:** Encontre qualquer emissora, filme ou série digitando apenas uma letra.
- 🔊 **Equalizador & Decodificação GZIP Multi-Threading:** Servidor em Python com tratamento inteligente de cabeçalhos HLS para máxima velocidade de carregamento.
- 📐 **Ajuste de Proporção de Tela Inteligente:** Alterne entre 16:9 Cinema, Preencher Tela ou Esticar 100% com apenas um toque na tecla **`A`**.

## ⌨️ Atalhos de Teclado (Para PC e Smart TV)

| Tecla | Ação |
| :---: | :--- |
| **`Espaço`** | Pausar / Reproduzir transmissão |
| **`↓` ou `N`** | Próximo canal |
| **`↑` ou `P`** | Canal anterior |
| **`A`** | Alternar proporção de tela (16:9 Cinema ➔ Preencher ➔ Esticar) |
| **`M`** | Ligar / Desligar som (Mudo) |
| **`F`** | Modo Tela Cheia |
| **`C`** | Alternar Modo Cinema Ultra-Escuro |
| **`1` a `9`** | Sintonizar canais rápidos |
| **`?`** | Abrir painel interativo de ajuda |

## 💻 Instalação Rápida no Windows (Em 1 Clique)

Você pode rodar todo o sistema no seu computador em menos de 10 segundos:

### 1. Clonar o Repositório
```powershell
git clone https://github.com/jonasskynet-eng/cine-pro-tv-2026.git
cd cine-pro-tv-2026
```

### 2. Iniciar a Central
Dê dois cliques no arquivo **`iniciar_central.bat`** ou execute pelo terminal:
```powershell
python "ECOSSISTEMA_STREAMING_IPTV\servidor_streaming_local.py"
```

O navegador abrirá automaticamente em `http://localhost:8080/index.html` com o player pronto e acelerado!
